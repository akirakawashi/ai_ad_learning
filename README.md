# AI Ad Learning

Подготовка данных для дообучения детектора щитов. Фотографии прогоняются через
рабочую модель, разметка сохраняется в YOLO-формате, а отчёт показывает, какие
кадры править руками в первую очередь.

Соседние репозитории: `../ai_ad_ml` — пайплайн и воркер, откуда взяты веса,
`../ai_ad_backend` — канон и документация проекта.

## Требования

- Python 3.12 и `uv`;
- GPU (без неё прогон идёт на процессоре и занимает часы);
- веса детектора в `models/detection/best.pt` — копия из `../ai_ad_ml`;
- фотографии в `raw/`.

Ни веса, ни фотографии, ни результат прогона в Git не попадают.

## Настройка

```bash
uv sync
cp ../ai_ad_ml/models/detection/best.pt models/detection/best.pt
```

Версия `ultralytics` закреплена ровно той, что стоит в пайплайне. Разметка должна
получиться такой же, какую увидит рабочая модель, иначе правится не то.

## Запуск

```bash
uv run python run_prelabel.py
```

Полезные ключи: `--source` и `--output` для других папок, `--conf` для порога
записи рамки, `--weak-conf` для границы «посмотреть глазами», `--imgsz`,
`--batch`, `--device`.

## Что на выходе

```text
prelabel/
├── labels/              разметка, по .txt на каждую фотографию
├── images/              симлинки на raw — датасет для обучения
├── data.yaml            описание набора для ultralytics
├── report.csv           строка на фотографию: рамки, уверенность, статус
├── review.txt           порядок ручной проверки
└── cvat_annotations.zip импорт разметки в CVAT
```

Пустой `.txt` означает «на кадре ничего нет» и остаётся на месте намеренно:
отрицательные примеры нужны обучению не меньше положительных.

## Правка в CVAT

Задача создаётся из папки `raw/`, разметка заливается импортом
`cvat_annotations.zip` в формате YOLO 1.1. Фотографии в архив не кладутся — CVAT
берёт их из самой задачи.

Порог записи рамки ниже боевого: стереть лишнюю рамку быстрее, чем нарисовать
пропущенную. Обратная сторона — часть рамок окажется мусором, и их надо снять.

Смотреть все 7742 кадра подряд незачем. `review.txt` ставит вперёд кадры, где
модель не нашла ничего, за ними — кадры со слабыми рамками, от самой сомнительной.
Уверенные кадры в список не попадают.

Уверенность в YOLO-формате не хранится, и в CVAT рамка на 0.26 выглядит так же,
как рамка на 0.95. Различить их можно только по `report.csv`.
