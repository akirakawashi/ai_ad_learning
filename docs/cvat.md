# Правка разметки в CVAT

```bash
uv run adlearn detect bundle
```

Собирает пачки только из кадров, которым нужен человек — со статусами `пусто` и
`слабая`. Уверенные в пачки не идут. Всё складывается в
`data/detection/export/`: `part_NN_images.zip` и парный к нему
`part_NN_annotations.zip`.

Пачками, а не одной кучей: задача на несколько тысяч кадров грузится через
браузер долго и открывается тяжело, а упавшая загрузка отменяет всю работу
целиком. Размер пачки — `--chunk`, по умолчанию 600 кадров.

## Порядок

1. Завести метку **`ad_object`**. Имя должно совпасть буквально, иначе импорт
   ничего не найдёт и молча создаст пустую задачу.
2. Создать задачу из `part_NN_images.zip`.
3. `Actions → Upload annotations → YOLO 1.1 → part_NN_annotations.zip`.
4. Поправить руками.
5. `Actions → Export annotations → YOLO 1.1`.

Выгруженный архив идёт на вход `adlearn detect build --export`.

Если нужен весь набор целиком, а не только спорные кадры: задача создаётся из
папки `data/raw/`, а разметка заливается из
`data/detection/prelabel/cvat_annotations.zip` — там лежат все файлы.

## О чём помнить

Порог записи рамки ниже боевого, поэтому часть рамок — мусор, и их надо снять.
Пропущенную рамку нарисовать дороже, чем стереть лишнюю, — отсюда и перекос.

Уверенность в YOLO-формате не хранится: в CVAT рамка на 0.26 выглядит так же,
как рамка на 0.95. Различить их можно только по `report.csv`.

Фотографии в `part_NN_annotations.zip` не кладутся — CVAT берёт их из самой
задачи. Дублировать два с половиной гигабайта ради разметки незачем.
